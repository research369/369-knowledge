# Claude Code – 369 Research Knowledge Layer

**Arbeitsregeln, geprüft am 19.11.2026.**

## Einstieg und Fakten

- Vor jeder Aufgabe README.md, docs/AGENTS.md, docs/API.md, Ontologie und die betroffenen Datenmodelle lesen.
- Dieses Repository beschreibt ein separates Wissenssystem. Shop, WaWi und peptidpen.de sind laut README abgegrenzte Systeme; keine gemeinsame Datenbank oder Live-Verbindung unterstellen.
- Wissenschaftliche und Produktfakten mit datierter Primärquelle, Fundstelle und Aussagegrenze dokumentieren. Anbieterangaben, vorläufige Hinweise und bestätigte Forschung getrennt halten.
- README.md beschreibt einen Projektaufbau; vor Aussagen über aktuellen Live-Betrieb, Inhalte oder API-Zugriff den tatsächlichen Stand prüfen.

## Änderungen

- Bestehende Entitäten, Ontologie, API-Verträge, Moderation und Freigaben erhalten.
- Keine Entität veröffentlichen oder Admin-/API-Schlüssel anlegen, ändern oder widerrufen, außer der Auftrag nennt genau diese Aktion.
- Auf eigenem Branch arbeiten; Diff und die im Repository dokumentierten Prüfungen vor PR prüfen. Kein direkter Push auf main und keine Bereitstellung ohne Einzelauftrag.
- Keine privaten Personen-, Kunden- oder Zugangsdaten in Knowledge-Inhalte, Beispieldaten oder Logs übernehmen. Secrets nicht aus Beispielen kopieren.
